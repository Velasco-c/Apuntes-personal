# Base de Datos

Colección estructurada de datos lógicamente coherentes que representan [entidades](entidad.md) del mundo real.

## Jerarquía de Información
- **[Dato](dato.md):** El nivel atómico. Valores crudos (números, strings, binarios) sin contexto ni interpretación.
- **[Información](informacion.md):** Datos procesados, organizados y estructurados que poseen significado y permiten la toma de decisiones.

## Elementos constitutivos
- **[Entidad](entidad.md):** Unidad de [información](informacion.md) significativa en el sistema (ej. Cliente, Producto).
- **[Atributo](atributo.md):** Característica que describe a una entidad.
- **Dominio:** El conjunto de valores permitidos para un atributo específico.
