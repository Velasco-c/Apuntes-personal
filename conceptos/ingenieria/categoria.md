# Ingeniería de software

Principios, patrones y prácticas para organizar el código: cómo se diseñan los componentes, cómo se transportan y validan los datos, cómo se manejan los errores y cómo se prueba el software.

## Conceptos

- [DTO (Data Transfer Object)](dto.md): Un DTO (Data Transfer Object, objeto de transferencia de datos) es un patrón de diseño que define un objeto simple para transportar datos entre capas o componentes de una aplicació…
- [Escalabilidad](escalabilidad.md): La escalabilidad es la capacidad de un sistema para atender más carga, como más usuarios, más peticiones o más datos, sin perder rendimiento de forma inaceptable.
- [Manejo centralizado de errores](manejo-centralizado-de-errores.md): El manejo centralizado de errores es un patrón en el que todos los errores de la aplicación se entregan a un único manejador, que decide la respuesta que se envía.
- [Patrón de diseño](patron-de-diseno.md): Un patrón de diseño es una solución probada y reutilizable para un problema recurrente de diseño de software.
- [Principios SOLID](solid.md): SOLID es un conjunto de cinco principios de diseño orientado a objetos que buscan código fácil de mantener, extender y probar.
- [Sanitización de datos](sanitizacion-de-datos.md): La sanitización de datos es el proceso que limpia o transforma los datos de entrada para dejarlos en una forma uniforme y segura.
- [Testing automatizado](testing.md): El testing automatizado consiste en verificar el comportamiento del software mediante pruebas que se ejecutan de forma automática y repetible.
- [Validación de datos](validacion-de-datos.md): La validación de datos es el proceso que comprueba que los datos recibidos cumplen las reglas esperadas antes de procesarlos o almacenarlos.
