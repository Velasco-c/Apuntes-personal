# Atributo Multivaluado

Característica de una [Entidad](entidad.md) que puede contener múltiples valores para un único registro.

- *Ejemplo:* Un 'Número de Teléfono' si un usuario tiene varios, o 'Idiomas'.
- *Nota:* En el [modelo relacional](base-de-datos-relacional.md), estos suelen requerir una [tabla](tabla.md) separada para evitar repetir datos (evitar listas separadas por comas).

## Conceptos cercanos

- [Modelo Entidad-Relación (MER)](mer.md): Técnica de modelado conceptual utilizada en la fase de requerimientos para representar la estructura de datos mediante diagramas E-R.
- [Entidad](entidad.md): Representación abstracta de un objeto, persona, concepto o evento del mundo real que es relevante para el sistema de información.
- [Atributo](atributo.md): Propiedad o característica que describe a una Entidad en el modelo de datos.
- [Cardinalidad](cardinalidad.md): Restricción que define el número de ocurrencias de una Entidad que pueden relacionarse con otra en un MER.
- [Tabla (Base de Datos)](tabla.md): Estructura fundamental para organizar información en filas y columnas.
- [Modelo Lógico Relacional](modelo-logico-relacional.md): Etapa de diseño donde el MER se transforma en una estructura de tablas lista para ser implementada en un SGBD.
