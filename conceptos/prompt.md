# Prompt

Instrucción o contexto que se le da a un modelo para obtener una respuesta. Su redacción influye mucho en la calidad del resultado.

## Conceptos cercanos

- [Modelo de lenguaje de gran escala (LLM)](llm.md): Red neuronal entrenada con enormes volúmenes de texto para predecir el siguiente fragmento de texto.
- [Información](informacion.md): Conjunto organizado de datos procesados que poseen un significado, contexto y propósito dentro de un sistema.
- [Base de Datos](base-de-datos.md): Colección estructurada de datos lógicamente coherentes que representan entidades del mundo real.
- [Alucinación](alucinacion.md): Respuesta de un modelo de lenguaje que suena plausible pero es falsa o no está respaldada por fuentes.
- [Dato](dato.md): Unidad mínima de información, desprovista de contexto o interpretación por sí misma.
- [Model Context Protocol (MCP)](mcp.md): Protocolo abierto que estandariza la forma en que un modelo de IA se conecta con herramientas y fuentes de datos externas.
