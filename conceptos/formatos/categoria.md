# Formatos de datos

Formatos de texto para representar datos estructurados que se intercambian entre sistemas.

<!-- auto:contenido -->
## Conceptos

- [JSON](json.md): JSON (JavaScript Object Notation) es un formato de texto ligero para representar datos estructurados mediante pares clave-valor y arreglos.
- [XML](xml.md): XML (Extensible Markup Language) es un lenguaje de marcas que organiza la información en etiquetas anidadas.
