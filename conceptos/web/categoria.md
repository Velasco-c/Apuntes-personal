# Web y APIs

Conceptos de la web y de las APIs: protocolos, rutas, peticiones y respuestas, y los elementos de Express que los implementan.

## Conceptos

- [API](api.md): Una API (Application Programming Interface, interfaz de programación de aplicaciones) es un conjunto de definiciones y protocolos que permiten que componentes de software se comuni…
- [Código de estado HTTP](codigo-de-estado-http.md): Un código de estado HTTP es un número de tres dígitos que el servidor devuelve para indicar el resultado de una solicitud.
- [DOM (Document Object Model)](dom.md): El DOM (Document Object Model) es la representación en forma de árbol de un documento HTML.
- [Encabezado HTTP](encabezado-http.md): Un encabezado HTTP (header) es un metadato que se envía junto con una petición o una respuesta.
- [Endpoint](endpoint.md): Un endpoint es una combinación de un método HTTP y una ruta que el servidor atiende, por ejemplo GET /campus.
- [Express](express.md): Express es un marco de trabajo minimalista y flexible para Node.js que simplifica la creación de aplicaciones web y APIs.
- [express-validator](express-validator.md): express-validator es una biblioteca para Express que permite declarar reglas de validación y sanitización sobre los datos de una petición, y consultar sus errores.
- [HTTP](http.md): HTTP (Hypertext Transfer Protocol) es el protocolo de comunicación de la web.
- [Middleware](middleware.md): Un middleware es una función que recibe el objeto de solicitud (req), el de respuesta (res) y la función next, y forma parte de una pila que se ejecuta en secuencia cuando llega un…
- [Modelo cliente-servidor](modelo-cliente-servidor.md): El modelo cliente-servidor es una arquitectura en la que un servidor provee recursos y servicios, y uno o varios clientes los solicitan y consumen mediante peticiones.
- [Parámetro de ruta](parametro-de-ruta.md): Un parámetro de ruta es una parte variable de una URL que el servidor captura y entrega a la aplicación.
- [Router](router.md): Un router es un objeto que agrupa rutas relacionadas en un módulo independiente.
