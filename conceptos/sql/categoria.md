# SQL

El lenguaje SQL y las construcciones que se usan para consultar, modificar y programar datos. Estos conceptos son generales; cada motor los implementa con sus diferencias.

<!-- auto:contenido -->
## Conceptos

- [CRUD](crud.md): CRUD es el acrónimo de Create, Read, Update, Delete: las cuatro operaciones básicas que se realizan sobre cualquier dato almacenado.
- [CTE](cte.md): Una CTE (Common Table Expression, expresión de tabla común) es una consulta temporal con nombre, definida con WITH al inicio de una sentencia.
- [Evento programado](evento-programado.md): Un evento programado es una tarea que el servidor de base de datos ejecuta según un calendario, por ejemplo cada noche, o una sola vez en un momento determinado.
- [Función de ventana](funcion-de-ventana.md): Una función de ventana calcula un valor para cada fila usando un conjunto de filas relacionadas con ella, definido con la cláusula OVER.
- [JOIN](join.md): Un JOIN es una operación SQL que combina filas de dos o más tablas según una condición.
- [Procedimiento almacenado](procedimiento-almacenado.md): Un procedimiento almacenado es un bloque de sentencias SQL guardado en el servidor de base de datos, que se invoca por su nombre y puede recibir parámetros.
- [SQL](sql.md): SQL (Structured Query Language) es el lenguaje estándar para definir, consultar y manipular datos en bases de datos relacionales.
- [Trigger](trigger.md): Un trigger (disparador) es un bloque de código que se ejecuta automáticamente cuando ocurre un INSERT, un UPDATE o un DELETE sobre una tabla.
