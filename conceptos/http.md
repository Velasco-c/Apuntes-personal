# HTTP

Protocolo de comunicación de la web en el que el cliente envía solicitudes con un método y una ruta, y el servidor responde con un [código de estado](codigo-de-estado-http.md), [encabezados](encabezado-http.md) y, si corresponde, un cuerpo.
