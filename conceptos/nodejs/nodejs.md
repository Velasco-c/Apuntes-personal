# Node.js

<!-- auto:categoria -->
Categoría: [Node.js y herramientas](categoria.md)
<!-- /auto:categoria -->

**Node.js** es un entorno de ejecución de código abierto y multiplataforma que permite ejecutar JavaScript fuera del navegador. Se basa en el motor V8 de Chrome y en un modelo de entrada y salida asíncrono y orientado a eventos.

## Características

* **Asíncrono:** una operación que espera, como leer un archivo o consultar una base de datos, no detiene el resto del programa.
* **Multiplataforma:** funciona en Windows, Linux y macOS.
* **Ecosistema:** el gestor de paquetes [npm](npm.md) da acceso a una gran cantidad de bibliotecas.

## Usos habituales

Servidores web y APIs, herramientas de línea de comandos, herramientas de compilación y aplicaciones en tiempo real.
