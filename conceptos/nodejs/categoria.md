# Node.js y herramientas

Node.js, su entorno de ejecución, el gestor de paquetes y las herramientas que se usan durante el desarrollo.

<!-- auto:contenido -->
## Conceptos

- [dotenv](dotenv.md): dotenv es una biblioteca de Node.js que carga las variables definidas en un archivo .env dentro de process.env cuando arranca la aplicación.
- [Node.js](nodejs.md): Node.js es un entorno de ejecución de código abierto y multiplataforma que permite ejecutar JavaScript fuera del navegador.
- [nodemon](nodemon.md): nodemon es una herramienta de desarrollo que observa los archivos de un proyecto Node.js y reinicia el servidor automáticamente cuando detecta cambios.
- [npm (Node Package Manager)](npm.md): npm (Node Package Manager) es el gestor de paquetes de Node.js.
- [nvm (Node Version Manager)](nvm.md): nvm (Node Version Manager) es un administrador de versiones de Node.js.
