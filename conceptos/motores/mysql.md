# MySQL

<!-- auto:categoria -->
Categoría: [Motores de base de datos](categoria.md)
<!-- /auto:categoria -->

**MySQL** es un sistema gestor de bases de datos relacionales de código abierto, muy usado en aplicaciones web. Lo desarrolló originalmente MySQL AB y hoy pertenece a Oracle.

## Características

* Usa el motor InnoDB por defecto, que ofrece transacciones, claves foráneas e índices.
* Implementa [SQL](../sql/sql.md) con extensiones propias, como `AUTO_INCREMENT`.
* Incluye herramientas de administración, como MySQL Workbench.

## Uso típico

Aplicaciones web y de gestión que necesitan una base de datos relacional confiable y fácil de desplegar. Se conecta desde lenguajes como PHP, Java o Node.js mediante un [controlador de base de datos](../acceso-a-datos/controlador-de-base-de-datos.md).
