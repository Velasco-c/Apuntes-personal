# API (Interfaz de programación de aplicaciones)

Conjunto de definiciones y protocolos que permiten que componentes de software se comuniquen e integren, especificando las rutinas, estructuras de datos y variables que otros programas pueden utilizar.

## Conceptos cercanos

- [Información](informacion.md): Conjunto organizado de datos procesados que poseen un significado, contexto y propósito dentro de un sistema.
- [Base de Datos](base-de-datos.md): Colección estructurada de datos lógicamente coherentes que representan entidades del mundo real.
- [Node.js](nodejs.md): Entorno de ejecución que permite ejecutar JavaScript fuera del navegador.
- [JSON](json.md): Formato de texto ligero para representar datos semiestructurados con pares clave-valor y arreglos.
- [Modelo de lenguaje de gran escala (LLM)](llm.md): Red neuronal entrenada con enormes volúmenes de texto para predecir el siguiente fragmento de texto.
- [MySQL](mysql.md): Sistema de gestión de bases de datos relacionales de código abierto.
