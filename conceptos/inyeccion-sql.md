# Inyección SQL

Vulnerabilidad que ocurre cuando datos del usuario se concatenan directamente en una consulta [SQL](sql.md) y alteran su significado. Se evita enviando los valores como parámetros en una [consulta preparada](prepared-statement.md).

## Conceptos cercanos

- [MySQL](mysql.md): Sistema de gestión de bases de datos relacionales de código abierto.
- [SQL](sql.md): Lenguaje estándar para definir, consultar y manipular datos en bases de datos relacionales.
- [Base de Datos](base-de-datos.md): Colección estructurada de datos lógicamente coherentes que representan entidades del mundo real.
- [Tabla (Base de Datos)](tabla.md): Estructura fundamental para organizar información en filas y columnas.
- [Prepared statement](prepared-statement.md): Sentencia SQL con marcadores de posición para los valores.
- [Procedimiento almacenado](procedimiento-almacenado.md): Bloque de sentencias SQL guardado en el servidor, que se invoca por nombre y puede recibir parámetros.
