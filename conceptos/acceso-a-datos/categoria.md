# Acceso a datos desde una aplicación

Cómo una aplicación se conecta a una base de datos y ejecuta consultas de forma eficiente y segura. Los conceptos aplican a cualquier lenguaje y a cualquier motor.

<!-- auto:contenido -->
## Conceptos

- [Controlador de base de datos](controlador-de-base-de-datos.md): Un controlador (driver) de base de datos es la biblioteca que permite a una aplicación comunicarse con un motor concreto: abre la conexión, envía las consultas y recibe los resulta…
- [Inyección SQL](inyeccion-sql.md): La inyección SQL es una vulnerabilidad que ocurre cuando datos proporcionados por el usuario se concatenan directamente en una consulta SQL, de modo que pueden alterar su significa…
- [Pool de conexiones](pool-de-conexiones.md): Un pool de conexiones es un conjunto de conexiones abiertas a la base de datos que la aplicación comparte y reutiliza.
- [Prepared statement](prepared-statement.md): Una sentencia preparada (prepared statement) es una consulta SQL cuya estructura se envía al motor por separado de sus valores.
