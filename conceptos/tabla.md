# Tabla (Base de Datos)

Estructura fundamental para organizar [información](informacion.md) en filas y columnas.

## Componentes
- **[Tupla](tupla.md) (Registro):** Fila que representa una instancia única de una [entidad](entidad.md).
- **[Atributo](atributo.md) (Columna):** Propiedad o característica de la entidad.

## Integridad
- **[Llave Primaria](llave-primaria.md) ([PK](llave-primaria.md)):** Identificador único del registro; garantiza unicidad y no duplicidad.
- **[Llave Foránea](llave-foranea.md) ([FK](llave-foranea.md)):** Puente entre tablas; referencia a la PK de una tabla "padre".

## Conceptos cercanos

- [Información](informacion.md): Conjunto organizado de datos procesados que poseen un significado, contexto y propósito dentro de un sistema.
- [Base de Datos](base-de-datos.md): Colección estructurada de datos lógicamente coherentes que representan entidades del mundo real.
- [SQL](sql.md): Lenguaje estándar para definir, consultar y manipular datos en bases de datos relacionales.
- [Llave Primaria (PK)](llave-primaria.md): Un Atributo o conjunto de atributos que identifica de manera única e inequívoca a cada Tupla dentro de una Tabla.
- [Índice](indice.md): Estructura auxiliar que permite localizar filas por el valor de una o más columnas sin recorrer toda la tabla.
- [MySQL](mysql.md): Sistema de gestión de bases de datos relacionales de código abierto.
