# Inteligencia artificial

Conceptos de inteligencia artificial: modelos de lenguaje, instrucciones a los modelos, redes neuronales y sistemas expertos.

<!-- auto:contenido -->
## Conceptos

- [Alucinación](alucinacion.md): Una alucinación en un modelo de lenguaje es una respuesta que suena plausible, pero es falsa o no está respaldada por fuentes.
- [Base de conocimiento](base-de-conocimiento.md): Una base de conocimiento es un conjunto estructurado de hechos y reglas que un sistema experto usa para razonar.
- [Function calling](function-calling.md): El function calling es un mecanismo por el que un modelo de lenguaje solicita ejecutar una función definida por la aplicación, con argumentos estructurados, y después usa el result…
- [Model Context Protocol (MCP)](mcp.md): El Model Context Protocol (MCP) es un protocolo abierto que estandariza la forma en que un modelo de IA se conecta con herramientas y fuentes de datos externas.
- [Modelo de lenguaje de gran escala (LLM)](llm.md): Un modelo de lenguaje de gran escala (LLM, Large Language Model) es una red neuronal entrenada con grandes volúmenes de texto para predecir el siguiente fragmento de texto.
- [Motor de inferencia](motor-de-inferencia.md): Un motor de inferencia es el componente de un sistema experto que aplica las reglas de la base de conocimiento a los hechos disponibles para deducir nuevas conclusiones.
- [Prompt](prompt.md): Un prompt es la instrucción o el contexto que se entrega a un modelo de lenguaje para obtener una respuesta.
- [Red neuronal](red-neuronal.md): Una red neuronal artificial es un modelo computacional inspirado en las neuronas biológicas.
- [Sistema experto](sistema-experto.md): Un sistema experto es un programa que resuelve problemas en un dominio especializado, aplicando una base de conocimiento y reglas de inferencia.
