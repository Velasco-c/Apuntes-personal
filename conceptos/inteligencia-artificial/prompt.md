# Prompt

<!-- auto:categoria -->
Categoría: [Inteligencia artificial](categoria.md)
<!-- /auto:categoria -->

Un **prompt** es la instrucción o el contexto que se entrega a un modelo de lenguaje para obtener una respuesta. Su redacción influye mucho en la calidad del resultado: una instrucción clara, con contexto y formato esperado, suele producir respuestas más útiles.

## Partes habituales

* **Instrucción:** qué debe hacer el modelo.
* **Contexto:** información de referencia que el modelo debe usar.
* **Restricciones:** formato, longitud o tono de la respuesta.
* **Ejemplos:** casos de entrada y salida esperados.

## Buenas prácticas

Ser específico, indicar el formato de salida, pedir pasos cuando la tarea es compleja y verificar las respuestas con fuentes externas, porque un modelo puede [alucinar](alucinacion.md).
