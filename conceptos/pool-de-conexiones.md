# Pool de conexiones

Conjunto de conexiones abiertas y reutilizables que la aplicación comparte, en lugar de abrir una nueva por cada consulta. Reduce el costo de conectarse a la [base de datos](base-de-datos.md).

## Conceptos cercanos

- [Persistencia de datos](persistencia.md): Capacidad de conservar los datos más allá de la ejecución del programa, por ejemplo en archivos o en una base de datos.

- [MySQL](mysql.md): Sistema de gestión de bases de datos relacionales de código abierto.
- [Node.js](nodejs.md): Entorno de ejecución que permite ejecutar JavaScript fuera del navegador.
- [Información](informacion.md): Conjunto organizado de datos procesados que poseen un significado, contexto y propósito dentro de un sistema.
- [Tabla (Base de Datos)](tabla.md): Estructura fundamental para organizar información en filas y columnas.
