# Modelado de datos

Cómo se diseña una base de datos antes de implementarla: se identifican entidades, atributos y relaciones, y después se transforman en tablas normalizadas.

<!-- auto:contenido -->
## Conceptos

- [Atributo](atributo.md): Un atributo es una propiedad que describe a una entidad.
- [Cardinalidad](cardinalidad.md): La cardinalidad indica cuántas ocurrencias de una entidad pueden relacionarse con cuántas ocurrencias de otra.
- [Entidad](entidad.md): Una entidad es la representación de un objeto, persona, concepto o evento del mundo real que es relevante para el sistema y sobre el que se almacena información.
- [Modelo entidad-relación (MER)](mer.md): El modelo entidad-relación (MER) es una técnica de modelado conceptual que describe los datos de un sistema mediante entidades, atributos y relaciones, representados en un diagrama…
- [Modelo lógico relacional](modelo-logico-relacional.md): El modelo lógico relacional es la etapa de diseño en la que el MER se transforma en un conjunto de tablas, columnas, claves y restricciones.
- [Normalización](normalizacion.md): La normalización es un proceso de diseño que organiza las tablas para reducir la redundancia y evitar anomalías al insertar, actualizar o eliminar datos.
- [Relación entre entidades](relacion.md): Una relación es una asociación entre dos o más entidades que describe cómo se vinculan sus ocurrencias.
