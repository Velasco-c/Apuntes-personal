# Bases de datos

Conceptos generales de las bases de datos, válidos para cualquier sistema gestor. Las subcategorías describen cómo se diseña una base de datos y cómo se organiza una vez implementada.

## Conceptos

- [Base de datos](base-de-datos.md): Una base de datos es una colección organizada de datos relacionados entre sí, almacenada de forma que pueda consultarse, modificarse y administrarse de manera controlada.
- [Base de datos relacional](base-de-datos-relacional.md): Una base de datos relacional organiza la información en tablas relacionadas entre sí mediante claves.
- [Sistema gestor de bases de datos (SGBD)](sgbd.md): Un sistema gestor de bases de datos (SGBD) es el software que crea, administra y da acceso a las bases de datos.
- [Transacción](transaccion.md): Una transacción es un conjunto de operaciones sobre una base de datos que se ejecutan como una sola unidad: o se completan todas, o no se aplica ninguna.
