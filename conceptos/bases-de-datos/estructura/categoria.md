# Estructura y claves

Los elementos con los que se construye una base de datos relacional ya implementada: tablas, filas, claves, índices y vistas.

<!-- auto:contenido -->
## Conceptos

- [Llave (clave)](llave.md): Una llave, también llamada clave, es un atributo o conjunto de atributos que identifica o relaciona filas dentro de una base de datos.
- [Llave foránea (FK)](llave-foranea.md): Una llave foránea (FK, foreign key) es un atributo de una tabla que referencia la llave primaria de otra tabla, o de la misma.
- [Llave primaria (PK)](llave-primaria.md): Una llave primaria (PK, primary key) es el atributo o conjunto de atributos que identifica de forma única e inequívoca cada fila de una tabla.
- [Tabla](tabla.md): Una tabla es la estructura básica de una base de datos relacional.
- [Tupla](tupla.md): Una tupla, también llamada fila o registro, es una ocurrencia única de una entidad dentro de una tabla.
- [Vista](vista.md): Una vista es una consulta guardada con un nombre, que se usa como si fuera una tabla.
- [Índice de base de datos](indice-bd.md): Un índice de base de datos es una estructura auxiliar que permite localizar filas por el valor de una o más columnas sin recorrer toda la tabla.
