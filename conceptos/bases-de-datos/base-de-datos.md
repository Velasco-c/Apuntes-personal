# Base de datos

<!-- auto:categoria -->
Categoría: [Bases de datos](categoria.md)
<!-- /auto:categoria -->

Una **base de datos** es una colección organizada de datos relacionados entre sí, almacenada de forma que pueda consultarse, modificarse y administrarse de manera controlada. Representa entidades del mundo real, como clientes, productos o pedidos.

## Componentes

* **Datos:** la información almacenada.
* **Estructura:** la forma en que se organizan los datos, con tablas, colecciones o documentos según el modelo.
* **Sistema gestor:** el software que controla el acceso, la integridad y la concurrencia. Ver [SGBD](sgbd.md).

## Modelos más comunes

El **modelo relacional** organiza los datos en tablas con claves, como [MySQL](../motores/mysql.md) o [PostgreSQL](../motores/postgresql.md). El **modelo documental** guarda documentos con estructura flexible, y el **modelo clave-valor** asocia cada valor a una clave. Esta nota describe los conceptos generales; el modelo relacional tiene su propia nota.
