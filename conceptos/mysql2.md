# mysql2

Controlador de [Node.js](nodejs.md) que permite a una aplicación comunicarse con servidores [MySQL](mysql.md). Ofrece una [API](api.md) basada en promesas, [pools de conexiones](pool-de-conexiones.md) y [consultas preparadas](prepared-statement.md).

## Conceptos cercanos

- [Node.js](nodejs.md): Entorno de ejecución que permite ejecutar JavaScript fuera del navegador.
- [Express.js](express.md): Marco de trabajo minimalista para Node.js que simplifica la creación de aplicaciones web y APIs, con herramientas para definir rutas, middlewares y manejar peticiones y respuestas…
- [MySQL](mysql.md): Sistema de gestión de bases de datos relacionales de código abierto.
- [Base de Datos](base-de-datos.md): Colección estructurada de datos lógicamente coherentes que representan entidades del mundo real.
- [Variable de entorno](variable-de-entorno.md): Valor de configuración definido fuera del código, como una dirección de servidor o una contraseña, que la aplicación lee en tiempo de ejecución desde process.env.
- [Pool de conexiones](pool-de-conexiones.md): Conjunto de conexiones abiertas y reutilizables que la aplicación comparte, en lugar de abrir una nueva por cada consulta.
